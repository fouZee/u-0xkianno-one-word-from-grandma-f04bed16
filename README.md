BEEPBOOP — the one word Grandma would text about AI: warm, a little baffled,
and doing her best robot impression in a single word. This program writes
exactly that word to `/output/entry.txt`, nothing else — no sentence, no
explanation, no punctuation tricks. One word, the sound she thinks the AI makes.

## Run it

```sh
python3 main.py
```

This writes `BEEPBOOP` (8 characters) to `/output/entry.txt`.
